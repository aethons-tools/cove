# Jam SPA, slice 5: session view, part 1 — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a session's home channel in the Jam app shows the session view, at parity with the old Inbox:
- the **header**: who the session is (label, kind, ticket, role · project · for owner, mission), what it's doing (state, tool, time in state, open asks), cost and this turn's cost (tokens in the tooltip), context use, uptime;
- its **actions**: Copy SSH, Interrupt, and a ⋯ menu with Compact, Clear, Release, Restart/End and Upgrade (with confirmations, and the server's refusal shown when one comes back);
- its **tabs**, which open a **resizable pane** beside or below the messages: Previews, Artifacts and Status. Thinking and Studio are listed and link to the old Inbox until slice 6;
- the **pane layout** (tab, placement, size) is remembered per session in localStorage. It uses the old Inbox's keys and shape, so the two UIs share it. A session never opened starts from the last layout used, `?tab=` opens a tab, and below 900 px the pane always sits below.

**Architecture:**
- **Go.** The session view models (`SessionHead`, `SessionPane` and its rows) move into `apitypes.go` with JSON tags.
- **Conversation link.** `Conversation.session` names the home session's id when the viewer may see it, using the same rule the old page uses to decide whether to show the head.
- **New routes:** `GET api/sessions/{id}`, `GET api/sessions/{id}/pane/{tab}` (previews, artifacts, status) and `POST api/sessions/{id}/{action}`.
- **Shared logic.** The pane builder and the action logic are each factored into one function shared with the HTML routes, so authorization and refusals stay identical.
- **App.** A `src/session/` module holds the pure layout functions, a `usePaneLayout` hook, `SessionHeader`, `SessionPane` (with its three tabs) and `SessionView`, which composes header, split and divider. `useLiveEvents` also invalidates `["session"]`.

**Tech Stack:** the slice 1–4 stack (Mantine `Menu`, `Modal` and `useMediaQuery` from `@mantine/hooks`). No new dependencies.

**Spec:** [`docs/superpowers/specs/2026-10-26-jam-spa-design.md`](../specs/2026-10-26-jam-spa-design.md):
- §3 slice 5: "the header (status, context %, cost, keep/release/restart/upgrade), the resizable pane with per-session layout in localStorage, and the Previews, Artifacts and Status tabs";
- §2: the route table, `api/sessions/{id}` and `api/sessions/{id}/pane/{tab}`, with session actions "taking and returning JSON";
- §4: authorization stays server-side.

Helpers already on main:
- Go: `writeJSON`, `writeAPIError`, `decodeJSON`, `checkJSONHeaders`, `getConv`, `sessionEnv`, `asPrincipal`, `env.homeOf`, `fakeOps`.
- TS: `apiGet`/`apiPost`, `POLL_MS`, `copyText`, `renderApp`, `boot`, `server` (MSW).
- Browser tests: `pageProblems`, `testChanges`, `browserCtx`, `into`, `call`.

## Global Constraints

- **Parity:** everything the old header and pane do for these tabs works.
  - The old HTML routes keep their exact status codes, texts and HX headers: `/app/user/session/{id}/head`, `…/pane?tab=` and `POST …/{action}`.
  - Their tests (`session_test.go`, `sessionpane_test.go`) pass unchanged, apart from the helper extraction in Task 1.
- **Authorization:** a session the viewer may not see answers exactly like a missing one (404 `not_found`, the same body). Every refusal comes from the server. The app hiding a button is never the check.
- **JSON:**
  - errors use `{"error","code"}`;
  - POSTs take a JSON body (`{}`) via `decodeJSON`;
  - lists are `[]`, never `null`;
  - every API type lives in `apitypes.go`, with `types.ts` regenerated by `go generate ./internal/jam/userui/`.
- **Status tab content:** aggregates only (state, runtime, totals), never event content (docs/usage/jam/session-events.md).
- **Shared storage:** `localStorage["jam-pane:" + id]` and `["jam-pane:last"]` hold `{"tab", "place", "w", "h"}`, exactly as `layout.html` writes them (`tab`: one of studio, thinking, previews, artifacts, status, or `null`; `place`: right or below; `w`/`h`: px).
- **Pane sizes:**
  - limits: at least 200 px for the pane, at least 240 px left for the messages;
  - default size: 380 px on the right, 280 px below;
  - the keyboard step is 24 px;
  - narrow means `(max-width: 900px)`.
- **CSP:** nothing inline. Images come from `'self'`; preview links are plain `<a target="_blank" rel="noopener">`, never framed in this slice.
- **Size budget:** initial JS ≤ 350 KB gzipped.
- **Docs:** they ship in the same change.
- **gofmt:** CI runs Go 1.26, which aligns map-literal keys differently from the sandbox's 1.27. Write table tests as positional struct literals, not maps with long keys.

## Review Focus

1. **A remembered or linked Studio tab for someone without the Studio tab** (no ssh right, or framing off) stays closed, and the saved layout is left as it was, so it opens again where it is allowed. (Task 4 test.)
2. **Foreign or corrupt `jam-pane:*` values** fall back to the defaults without breaking the view. That covers values the old Inbox wrote, `"null"`, a non-object, a bogus tab, a negative size, and a storage that throws. (Task 4 test.)
3. **The session ends or disappears while its conversation is open** (Release, Restart, or another person's action). After the refetch, the header and pane vanish and the conversation stays usable. There are no repeating error toasts. (Task 6 test.)
4. **A refused or failed action** (403, 409 while the session is busy, 502) shows the server's message as a red notification and changes nothing. (Task 3 Go test; Task 5 test.)
5. **A live refresh while the ⋯ menu or a confirmation is open** keeps it open. The old header held its refresh for this (`meMenuOpen`). (Task 5 test.)

func decodeAs[T any](t *testing.T, rec *httptest.ResponseRecorder) T {
	t.Helper()
	var v T
	if rec.Code != http.StatusOK {

	checkJSONHeaders(t, rec)

		t.Fatal(err)

	return v

// sessionOutcome runs action on inst for p, re-checking who may: 204, or the
// refusal's status, API code and text. Release, restart and upgrade are
// the owner's or an operator's; interrupt, compact and clear are anyone's
// who can see the session, while its activity allows (else 409). Shared by
// the HTML and API routes.
func (h *handler) sessionOutcome(r *http.Request, p jam.Participant, inst jam.Instance, action string) (int, string, string) {
	pr, _ := appui.PrincipalFrom(r)
	op := pr.Admin
	var err error
	switch action {
	case "release":
		if !mayRelease(inst, p, op) {
			return http.StatusForbidden, "forbidden", "only the session's owner (or an operator) may release it"
		}
		err = h.d.Ops.Teardown(r.Context(), inst.ActorID)
	case "restart":
		if !op || inst.SessionKind == jam.SessionKindPersonal {
			return http.StatusForbidden, "forbidden", "operators only"
		}
		err = h.d.Ops.Teardown(r.Context(), inst.ActorID)
	case "upgrade":
		if !op || inst.SessionKind != jam.SessionKindStanding {
			return http.StatusForbidden, "forbidden", "operators only, standing sessions"
		}
		_, err = h.d.Ops.Upgrade(inst)
	case string(jam.CmdInterrupt), string(jam.CmdCompact), string(jam.CmdClear):
		c := jam.SessionCommand(action)
		if a := jam.CommandActivity(inst); !jam.CommandAllowed(c, a) {
			return http.StatusConflict, "conflict", string(c) + " is not available while the session is " + string(a)
		}
		by := h.d.Intercom.PartyOf(p.UserID).Label
		if by == "" {
			by = string(p.UserID)
		}
		err = h.d.Ops.Command(r.Context(), inst, c, by)
	default:
		return http.StatusNotFound, "not_found", "no such session action"
	}
	if err != nil {
		h.lg.Error("session action failed", "session", inst.ActorID, "action", action, "error", err.Error())
		return http.StatusBadGateway, "action_failed", "the " + action + " failed; see the jam log"
	}
	h.lg.Info("session action", "session", inst.ActorID, "action", action, "by", string(p.UserID))
	return http.StatusNoContent, "", ""
}

// sessionAction is the HTML route: 204 (a page reload once the session
// ends, a refresh after an upgrade or a command); 403; 404 alike for
// missing and unseen; 409; 502.
func (h *handler) sessionAction(w http.ResponseWriter, r *http.Request) {
	p, ok := jam.ParticipantFrom(r)
	if !ok {
		http.Error(w, "no participant", http.StatusUnauthorized)
		return
	}
	inst, _, ok := h.sessionFor(p, r.PathValue("id"))
	if !ok || h.d.Ops == nil {
		http.NotFound(w, r)
		return
	}
	action := r.PathValue("action")
	status, _, msg := h.sessionOutcome(r, p, inst, action)
	switch {
	case status == http.StatusNotFound:
		http.NotFound(w, r)
		return
	case status != http.StatusNoContent:
		http.Error(w, msg, status)
		return
	}
	switch action {
	case "upgrade", string(jam.CmdInterrupt), string(jam.CmdCompact), string(jam.CmdClear):
		w.Header().Set("HX-Trigger", "meChanged")
	default:
		w.Header().Set("HX-Refresh", "true") // the session is going: reload rather than refresh a head that 404s
	}
	w.WriteHeader(http.StatusNoContent)
}

// The session pane's layout, stored as the old Inbox stores it (layout.html's
// mePaneLoad/mePaneSave), so both UIs share it: localStorage
// "jam-pane:<session>" and "jam-pane:last" (the layout a session never
// opened starts from) hold {tab, place, w, h}.

export const PANE_TABS = ["studio", "thinking", "previews", "artifacts", "status"] as const;
export type PaneTab = (typeof PANE_TABS)[number];
export const TAB_LABEL: Record<PaneTab, string> = {
  studio: "Studio", thinking: "Thinking", previews: "Previews", artifacts: "Artifacts", status: "Status",
};
export const isTab = (v: unknown): v is PaneTab => typeof v === "string" && (PANE_TABS as readonly string[]).includes(v);

export type Place = "right" | "below";
export interface PaneLayout { tab: PaneTab | null; place: Place; w?: number; h?: number }

export const MIN_PANE = 200;
export const MIN_MAIN = 240;
export const KEY_STEP = 24;
export const DEFAULT_SIZE: Record<Place, number> = { right: 380, below: 280 };
export const NARROW = "(max-width: 900px)";

const size = (v: unknown) => (typeof v === "number" && Number.isFinite(v) && v > 0 ? Math.round(v) : undefined);

// parse keeps what's valid of a stored layout; anything else is the default.
function parse(raw: string | null): PaneLayout | null {
  if (!raw) return null;
  let v: unknown;
  try { v = JSON.parse(raw); } catch { return null; }
  if (!v || typeof v !== "object" || Array.isArray(v)) return null;
  const o = v as Record<string, unknown>;
  const l: PaneLayout = { tab: isTab(o.tab) ? o.tab : null, place: o.place === "below" ? "below" : "right" };
  const w = size(o.w), h = size(o.h);
  if (w) l.w = w;
  if (h) l.h = h;
  return l;
}

export function loadLayout(id: string): PaneLayout {
  try {
    return parse(localStorage.getItem("jam-pane:" + id)) ?? parse(localStorage.getItem("jam-pane:last")) ?? { tab: null, place: "right" };
  } catch {
    return { tab: null, place: "right" };
  }
}

export function saveLayout(id: string, l: PaneLayout): void {
  const v = JSON.stringify(l);
  try {
    localStorage.setItem("jam-pane:" + id, v);
    localStorage.setItem("jam-pane:last", v);
  } catch { /* storage full or denied: the layout lasts this page only */ }
}

// clampSize keeps the pane at least MIN_PANE, leaving the messages MIN_MAIN.
export const clampSize = (px: number, total: number) => Math.round(Math.max(MIN_PANE, Math.min(total - MIN_MAIN, px)));

Implement `usePaneLayout.ts`:

```ts
import { useMediaQuery } from "@mantine/hooks";
import { useEffect, useRef, useState } from "react";
import { DEFAULT_SIZE, isTab, loadLayout, NARROW, saveLayout, type PaneLayout, type PaneState, type PaneTab, type Place } from "./layout";

// usePaneLayout is one session's pane layout: loaded from storage (a linked
// ?tab= opens that tab and is saved), saved on each change. Narrow windows
// put the pane below without changing the saved placement. A Studio tab the
// viewer lacks (opts.studio false) shows closed, and the saved layout is
// left as it was.
export function usePaneLayout(id: string, opts: { studio: boolean; linked: string | null }): PaneState {
  const [layout, setLayout] = useState<PaneLayout>(() => {
    const l = loadLayout(id);
    return isTab(opts.linked) ? { ...l, tab: opts.linked } : l;
  });
  const narrow = useMediaQuery(NARROW) ?? false;
  const linked = isTab(opts.linked);
  useEffect(() => {
    if (linked && !(layout.tab === "studio" && !opts.studio)) saveLayout(id, layout);
    // Only the first layout: later changes save themselves.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);
  // latest is the newest layout set, for a drag's pointerup: its listener
  // was made in an earlier render, whose layout is the pre-drag one.
  const latest = useRef<PaneLayout | null>(null);
  const update = (next: PaneLayout, save = true) => {
    latest.current = next;
    setLayout(next);
    if (save) saveLayout(id, next);
  };
  const tab = layout.tab === "studio" && !opts.studio ? null : layout.tab;
  const place: Place = narrow ? "below" : layout.place;
  const key = place === "right" ? "w" : "h";
  return {
    tab, place, narrow,
    size: layout[key] ?? DEFAULT_SIZE[place],
    toggle: (t: PaneTab) => update({ ...layout, tab: tab === t ? null : t }),
    close: () => update({ ...layout, tab: null }),
    flip: () => update({ ...layout, place: layout.place === "right" ? "below" : "right" }),
    resize: (px: number, save = false) => update({ ...layout, [key]: Math.round(px) }, save),
    commit: () => saveLayout(id, latest.current ?? layout),
  };
}
```

Define the `PaneState` interface in `layout.ts`, so components import their types from one place:

```ts
export interface PaneState {
  tab: PaneTab | null; place: Place; narrow: boolean; size: number;
  toggle(t: PaneTab): void; close(): void; flip(): void; resize(px: number, save?: boolean): void; commit(): void;
}
```

A keyboard step resizes and saves in one call (`resize(px, true)`). A drag resizes without saving on each move, and its pointerup calls `commit()`, which saves `latest`.

The drag's listeners belong to the render at pointerdown, so their `layout` is the pre-drag one. That's harmless for `resize`, because only the size changes during a drag. It would be wrong for `commit`, which is why `commit` saves from the ref.

import { ActionIcon, Group, Text } from "@mantine/core";
import { useRef, type CSSProperties, type KeyboardEvent, type PointerEvent, type ReactNode } from "react";
import { SessionHeader } from "./SessionHeader";
import { useSessionHead } from "./useSession";
import { usePaneLayout } from "./usePaneLayout";
import { clampSize, KEY_STEP, MIN_MAIN, MIN_PANE, TAB_LABEL } from "./layout";
import { PaneBody } from "./PaneTabs";

const GROW: Record<string, number> = { ArrowLeft: 1, ArrowUp: 1, ArrowRight: -1, ArrowDown: -1 };

// SessionView is a session's home channel: its header, then the
// conversation (header, then messages) beside or above the session pane.
// A session that's gone (its head 404s) shows as a plain conversation.
export function SessionView({ id, channel, linked, onAsk, header, children }: {
  id: string; channel: string; linked: string | null; onAsk: (id: string) => void; header: ReactNode; children: ReactNode;
}) {
  const q = useSessionHead(id);
  const pane = usePaneLayout(id, { studio: !!q.data?.studio, linked });
  const split = useRef<HTMLDivElement>(null);
  const aside = useRef<HTMLElement>(null);
  const right = pane.place === "right";
  const open = !!q.data && pane.tab !== null;
  const total = () => {
    const r = split.current!.getBoundingClientRect();
    return right ? r.width : r.height;
  };
  const onKey = (e: KeyboardEvent) => {
    const grow = GROW[e.key];
    if (!grow) return;
    e.preventDefault();
    pane.resize(clampSize(pane.size + grow * KEY_STEP, total()), true);
  };
  const onDown = (e: PointerEvent<HTMLDivElement>) => {
    if (e.button !== 0) return;
    e.preventDefault();
    const div = e.currentTarget;
    div.setPointerCapture(e.pointerId);
    const move = (ev: globalThis.PointerEvent) => {
      const r = split.current!.getBoundingClientRect();
      pane.resize(clampSize(right ? r.right - ev.clientX : r.bottom - ev.clientY, right ? r.width : r.height));
    };
    const up = () => {
      div.removeEventListener("pointermove", move);
      div.removeEventListener("pointerup", up);
      div.removeEventListener("pointercancel", up);
      pane.commit();
    };
    div.addEventListener("pointermove", move);
    div.addEventListener("pointerup", up);
    div.addEventListener("pointercancel", up);
  };
  // The size is also clamped in CSS, so a window smaller than when it was
  // saved still leaves the messages room.
  const paneStyle: CSSProperties = right
    ? { flex: `0 0 ${pane.size}px`, minWidth: MIN_PANE, maxWidth: `calc(100% - ${MIN_MAIN}px)` }
    : { flex: `0 0 ${pane.size}px`, minHeight: MIN_PANE, maxHeight: `calc(100% - ${MIN_MAIN}px)` };
  return (
    <>
      {q.data && <SessionHeader head={q.data} tab={open ? pane.tab : null} onTab={pane.toggle} />}
      {header}
      <div ref={split} data-place={pane.place} style={{ flex: 1, minHeight: 0, display: "flex", flexDirection: right ? "row" : "column" }}>
        <div style={{ flex: 1, minWidth: 0, minHeight: 0, display: "flex", flexDirection: "column" }}>{children}</div>
        {open && (
          <>
            <div role="separator" tabIndex={0} aria-label="Resize the session pane" aria-orientation={right ? "vertical" : "horizontal"}
              onKeyDown={onKey} onPointerDown={onDown}
              style={{ flex: "0 0 5px", cursor: right ? "col-resize" : "row-resize", background: "var(--mantine-color-default-border)", touchAction: "none" }} />
            <aside ref={aside} aria-label="Session pane" style={{ ...paneStyle, display: "flex", flexDirection: "column", overflow: "hidden", minHeight: right ? 0 : MIN_PANE }}>
              <Group gap={6} px="sm" py={6} style={{ borderBottom: "1px solid var(--mantine-color-default-border)" }}>
                <Text fw={700} size="sm">{TAB_LABEL[pane.tab!]}</Text>
                <span style={{ flex: 1 }} />
                {!pane.narrow && <ActionIcon variant="subtle" size="sm" title="Move the pane right or below" aria-label="Move the pane right or below" onClick={pane.flip}>⇄</ActionIcon>}
                <ActionIcon variant="subtle" size="sm" aria-label="Close the pane" onClick={pane.close}>×</ActionIcon>
              </Group>
              <div id="session-pane-body" role="tabpanel" aria-label={TAB_LABEL[pane.tab!]} style={{ flex: 1, minHeight: 0, overflow: "auto", padding: "8px 12px 14px" }}>
                <PaneBody id={id} channel={channel} tab={pane.tab!} onAsk={onAsk} />
              </div>
            </aside>
          </>
        )}
      </div>
    </>
  );
}
