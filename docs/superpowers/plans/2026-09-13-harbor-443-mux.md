# harbor :443 Attach-gRPC Mux Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the Attach gRPC on harbor's cove-facing :443 TLS listener (content-type demux alongside the broker), and switch `cove-master` to a TLS dial so a hardened cove (443-only egress) can reach the Attach stream through the squid CONNECT proxy.

**Architecture:** A `serveMux` helper terminates TLS once on the :443 listener and uses `cmux` to split `content-type: application/grpc` to the real `grpc.Server.Serve` from everything else to the broker `http.Handler`. `cmdServe` is rewired to use it. `cove-master` swaps insecure creds for `credentials.NewTLS` (system trust); grpc-go's built-in proxy dialer does the CONNECT.

**Tech Stack:** Go 1.25, `github.com/soheilhy/cmux v0.1.5` (new dep, already in the module cache), `google.golang.org/grpc` + `…/credentials`, `…/health` (test only), stdlib `crypto/tls`,`crypto/x509`.

- **Module fetch is offline-only.** `GOPROXY` here is `direct` (blocked by the locked egress). `cmux v0.1.5` is already in the module cache, so run module commands as **`GOPROXY=off go mod tidy`** / `GOPROXY=off go build ./...` (cache-only). Do NOT attempt a network fetch.

```go
package main

import (
	"crypto/tls"
	"net"
	"net/http"

	"github.com/soheilhy/cmux"
	"google.golang.org/grpc"
)

// serveMux terminates TLS on lis, then multiplexes the decrypted stream onto two
// servers: requests with content-type application/grpc go to gs (the Attach gRPC
// server), everything else to httpHandler (the broker). TLS is terminated here,
// so gs must use default (insecure) server creds. It blocks until lis closes.
func serveMux(lis net.Listener, tlsCfg *tls.Config, gs *grpc.Server, httpHandler http.Handler) error {
	tlsLis := tls.NewListener(lis, tlsCfg)
	m := cmux.New(tlsLis)
	grpcL := m.MatchWithWriters(cmux.HTTP2MatchHeaderFieldSendSettings("content-type", "application/grpc"))
	httpL := m.Match(cmux.Any())
	go func() { _ = gs.Serve(grpcL) }()
	go func() { _ = (&http.Server{Handler: httpHandler}).Serve(httpL) }()
	return m.Serve()
}
```
